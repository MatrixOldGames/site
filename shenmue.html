Como aplicar o patch

  1. Confira sua versão

    O patch foi feito sobre o GDI da versão . Confira a ficha acima antes de começar.

  2. Baixe o patcher

    Instale o patcher, um programa gratuito para Windows.

  3. Aplique o .dcp

    Abra o patcher, escolha o arquivo .gdi do seu jogo e o patch .dcp do disco. Ele cria uma pasta nova com o jogo traduzido.

  4. Jogue

    Copie a pasta gerada para o GDEMU ou abra no emulador. Para CD-R, converta a imagem para CDI antes de gravar.
